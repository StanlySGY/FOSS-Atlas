# UI/UX 与产品完善

用户授权审查实际体验并直接改进，允许参考开源产品。保留资源导航、Wiki、图谱与部署视图的现有结构，不虚构资源事实或扩大为视觉重做。

实测问题：手机正文与操作 9–12px，分类入口深；巡检维护信息占首屏；比较仅 Home 内存状态，离开丢失，缺少用途和条件；收藏空态混淆；移动加载 +24 实增8；Wiki 复制失败静默。

验收：分类更容易找到；移动检索输入 16px、关键操作至少44px；所选资源具名可删除，跨刷新/页面可恢复，分享比较链接可直接打开；比较展示已收录的概览/场景/额度条件/日期来源，未知明确标识；原生模态隔离全局导航并支持 Escape/焦点归还；收藏空态与加载数量准确；复制失败可手动选取链接；全套测试/静态构建/桌面移动真浏览器通过。

参考：Karakeep 的搜索/列表收藏组织 https://docs.karakeep.app/；Fumadocs 的渐进式导航 https://fumadocs.dev/docs/ui/layouts/docs。只参考交互模式，未复制代码或许可证受限资产。
