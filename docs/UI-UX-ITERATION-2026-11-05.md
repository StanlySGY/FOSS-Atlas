# FOSS-Atlas UI/UX 迭代记录 — 2026-11-05

## 本轮目标

对首页 / Wiki / 图谱 / 自部署四个视图做下一阶段体验巡检。本轮沿用既有组件、URL 状态和布局体系，不增加新依赖，也不追加无明确用户价值的装饰功能。

## 发现与调整

### 移动端知识图谱首屏

在 390px 真实浏览器视口中，原图谱标题区约 157px、工具栏约 183px，画布约从 y=464px 才开始。顶部同时常驻“灵感漫游”“标签关系强调”“筛选与聚焦”和视图切换，次要的标签关系强调控制挤占了主要画布空间。

本轮处理：

- 将标签连线强调按钮移入默认折叠的“筛选与聚焦”面板，在需要时仍可操作，并保留 `aria-pressed` 状态。
- 删除重复的工具说明，标题描述只保留“工具关联 / 替代关系探索”这一主任务。
- 列表视图、灵感漫游和筛选入口继续常驻，不削弱主要入口。

### 其他核心路径巡检

- 390px 图谱切换列表后可搜索 284 个节点；搜索 Ollama 唯一命中，并能进入对应 Wiki。
- Ollama Wiki 的“更多信息与关联”可以展开来源、标签、替代项和反向链接。
- 320px Wiki 正文与元数据自然纵向排列，无横向溢出。
- 桌面 Wiki 保留正文 / 元数据双栏与章节目录；桌面图谱画布布局没有被移动端调整破坏。

## 真实浏览器验收

使用本地 Chromium / CDP 对构建后的静态预览实测：

| 视口 | 标题区 | 工具栏 | 画布起始 Y | 页面横向溢出 |
| --- | ---: | ---: | ---: | --- |
| 390px（调整前） | 157px | 183px | 464px | 无 |
| 390px（调整后） | 110px | 124px | 364px | 无 |
| 320px（调整后） | 133px | 167px | 430px | 无 |

390px 画布提前约 100px；320px 画布提前约 37px；两种视口均无横向溢出。筛选面板内“强调标签连线”可将 `aria-pressed` 从 false 正常切换为 true。1440px 桌面页面也无横向溢出；浏览器运行时异常为 0。

自动化验证：`npm test` 89/89；`npm run lint` 0 警告 / 0 错误；`npm run build` 成功，预渲染 190 个页面；`git diff --check` 通过。

## 后续优先级
