# LOLBAS

> Windows 原生二进制与脚本的滥用手册，说明哪些系统自带程序可被用来绕过防护。

## 核心功能 / 特点

- 按用途分类 Windows 自带的程序与脚本
- 列出每个程序可用的参数与用法示例
- 覆盖 exe、dll、脚本等多种滥用手法

## 适用场景

- Windows 环境下做权限维持与横向移动
- 蓝队排查系统里被滥用的原生程序
