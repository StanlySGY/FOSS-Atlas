# Outline

> 团队知识库与协作文档工具，用 Markdown 快速搭起结构清晰的内部 Wiki。

## 一句话总结

团队知识库与协作文档工具，用 Markdown 快速搭起结构清晰的内部 Wiki。

## 核心功能 / 特点

- 富文本与 Markdown 编辑，多人实时协作
- 层级化文档目录与全文搜索，便于查找
- 支持权限管理、评论与 Slack 等集成

## 适用场景

- 团队沉淀规章制度、流程与技术文档
- 作为公司内部 Wiki 替代零散的在线文档
