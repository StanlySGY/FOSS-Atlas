# OpenWeatherMap

> 提供全球天气数据的 API 服务，免费档每天可调用一千次。

## 核心功能 / 特点

- 查询实时天气、预报与历史气象数据
- 按城市名或经纬度坐标获取结果
- 免费档每天一千次调用，需注册密钥

## 适用场景

- 为应用或看板嵌入实时天气信息
- 按位置做出行、物流等场景的天气提醒
