# Replicate

> 托管开源模型的云平台，用一条 HTTP 请求即可运行模型并获取结果。

## 核心功能 / 特点

- 在云端运行社区上传的开源模型
- 提供 HTTP API 与多语言客户端库
- 按实际运行时长计费，支持自建部署

## 适用场景

- 无需自备显卡即可跑图像或语音模型
- 把第三方模型快速接进自己的应用
