# CloudFlare-ImgBed

> 搭建在 Cloudflare 上的免费图床，支持多种存储渠道并自带上传与管理界面。

## 核心功能 / 特点

- 支持 Telegram、R2、S3 等存储渠道
- 提供网页上传、粘贴上传与随机图接口
- 跑在 Cloudflare 免费额度上，成本极低

## 适用场景

- 给个人博客或 Markdown 文档放外链图片
- 不想买对象存储又想自建图床
