# Vikunja

> 自建看板与待办任务管理，提供 Web、桌面与移动端，数据完全自持。

## 核心功能 / 特点

- 看板、列表、甘特与标签多种视图，任务可分解为子任务
- 支持 Kanban 看板与标签、优先级、截止日期
- 自带 REST API 与 WebDAV，可接日历或其他工具

## 适用场景

- 用自建工具替代 Todoist / Trello，且不想把任务数据交出去
- 需要在多个设备上看同一份任务清单，包括手机
