# 腾讯混元

> 腾讯混元消费者聊天入口，面向个人用户提供模型对话体验；开发者 API 与资源包属于腾讯云独立产品。

## 核心功能 / 特点

- 通过网页使用腾讯混元对话能力
- 面向消费者交互，不等同于云开发者 API 控制台
- 模型、功能与可用权益以当前产品页面为准

## 适用场景

- 直接体验混元模型的日常问答与内容生成
- 在申请开发者 API 前区分消费者产品与云端 API 产品

## 使用边界与安全提醒

- 腾讯云开发者 API 的体验包、Token 配额与账单不自动适用于此消费者聊天入口
- 不要把旧混元平台的首次开通资源包理解为消费者网页的使用额度
