# 学AI上L站 · 月度精选帖

> timerring 在 L 站按月维护的高价值 AI 帖子索引：不囤书签、趁热打铁，每月把值得读的讨论与项目收进一篇帖，逐条一句话点评。

## 它是什么

![学AI上L站 · 月度精选帖插画](/wiki/img/linuxdo-ai-picks-banner.webp)

这是 linux.do「文档共建」板块的一个系列帖：作者 timerring 每月发一篇，把当月刷到的、个人认为有价值的 AI 相关帖子收拢成一份索引。系列的出发点很朴素——作者不囤书签，只相信趁热打铁，于是开帖边看边更新，也欢迎佬友在评论区推荐补充。

每期是独立的帖子，最新一期即本条目指向的 [2026.11 版](https://linux.do/t/topic/3106502)。

## 收录风格

- **两大板块**：每期分「帖子 / 项目 / 工具」与「文档」两部分，前者偏项目与讨论，后者偏教程、原理长文与实战经验。
- **逐条点评**：每条收录都是「一句简短点评 + 链接」，不是单纯堆链接；点评本身就有信息量。
- **内容取向**：几乎全部围绕 AI 开发与学习——Vibe Coding 实操、Claude Code / Cursor 使用技巧、MCP 与 Skills 生态、LLM 原理科普（MoE、KV Cache、Attention 变体）、AI 论文写作，以及值得跟的开源项目。
- **不是白嫖合集**：这一系列专注技术学习，基本不收羊毛、额度类内容；想找额度请看本图鉴的其他分类。

## 适合谁

- 想追 L 站 AI 讨论、但没时间天天刷信息流的人——每月读一篇索引即可跟上主线。
- 找教程想看「真人筛过一遍」的内容，而不是搜索引擎堆出来的结果。
- 做技术选型时想翻社区真实讨论与一手实测帖。

## 和本图鉴怎么配合

- 图鉴收「能用的工具与服务」，它收「值得读的帖子」：一个管上手，一个管追新。
- 它的收录里时常出现可进图鉴的开源项目，可以视为本图鉴的候选池；反过来，本图鉴每个条目的 Wiki 讲怎么用，它的点评讲为什么值得关注。
- 与 [[Awesome Hacking]]、[[free-programming-books]] 这类常青清单不同，它是按月流动的时间线，更适合「定期回访」而不是「一次查完」。

## 使用建议

- 帖子托管在 linux.do，阅读需要能正常访问该站。
- 月更节奏、收录口径是作者个人品味，把它当作「一位可靠佬友的阅读流」来用，而不是全量索引；被它收录不等于经过本图鉴复核。
