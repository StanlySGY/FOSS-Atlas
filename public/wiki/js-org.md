# js.org

> js.org 为 JavaScript 相关项目免费提供 .js.org 子域名，需要在 GitHub 上提交申请。

## 一句话总结

js.org 为 JavaScript 相关项目免费提供 .js.org 子域名，需要在 GitHub 上提交申请。

## 核心功能 / 特点

- 仅面向 JS 项目免费发放子域名
- 在 GitHub 仓库提交申请与配置
- 可指向 GitHub Pages 或自有站点

## 适用场景

- 给开源 JS 库配一个专属域名
- 让项目文档站点的地址更好记
