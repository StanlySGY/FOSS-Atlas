# Nginx Proxy Manager

> 带 Web 界面的反向代理与证书管理工具，用图形化操作替代手写 Nginx 配置。

## 一句话总结

带 Web 界面的反向代理与证书管理工具，用图形化操作替代手写 Nginx 配置。

## 核心功能 / 特点

- 图形界面添加域名、转发规则与 SSL 证书
- 自动申请并续期免费的 HTTPS 证书
- 支持访问控制列表、HTTP 重定向与流代理

## 适用场景

- 给内网多个自建服务统一分配域名和 HTTPS
- 不熟悉 Nginx 配置也想搭建反向代理的用户
