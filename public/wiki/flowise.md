# Flowise

> 拖拽式的 LLM 编排工具，用可视化节点搭出对话与 Agent 工作流。

## 一句话总结

拖拽式的 LLM 编排工具，用可视化节点搭出对话与 Agent 工作流。

## 核心功能 / 特点

- 以节点连线的方式编排 LLM 流程
- 内置大量模型、工具与向量库节点
- 可导出为接口供业务系统调用

## 适用场景

- 不想写代码就搭一个 LLM 应用
- 快速验证多步工作流的可行性
