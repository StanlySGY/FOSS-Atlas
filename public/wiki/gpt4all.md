# GPT4All

> Nomic 出品的本地 LLM 套件，模型可以完全离线地跑在个人电脑上。

## 一句话总结

Nomic 出品的本地 LLM 套件，模型可以完全离线地跑在个人电脑上。

## 核心功能 / 特点

- 提供桌面客户端与 Python 绑定
- 内置可下载的多种量化模型
- 支持离线推理与本地文档问答

## 适用场景

- 断网或隐私要求高的场景使用 LLM
- 作为本地模型推理的入门工具
