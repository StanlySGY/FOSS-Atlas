# Matrix / Synapse

> Matrix 协议的参考服务端，用来搭建去中心化即时通讯。

## 一句话总结

Matrix 协议的参考服务端，用来搭建去中心化即时通讯。

## 核心功能 / 特点

- 支持端到端加密的私聊与群聊
- 可与其它 Matrix 服务器互通消息
- 提供桥接，接入 IRC、Telegram 等平台

## 适用场景

- 自建聊天服务器，替代 Discord 等平台
- 需要跨组织、跨服务器互通消息的团队
