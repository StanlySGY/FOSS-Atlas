# Disify

> 邮箱校验服务，可判断邮箱是否有效以及是否为临时邮箱。

## 核心功能 / 特点

- 校验邮箱格式、域名与可达性
- 识别一次性或临时邮箱域名
- 提供简单的 HTTP 接口，返回 JSON

## 适用场景

- 注册流程中拦截临时邮箱与无效地址
- 清洗用户列表里的可疑邮箱
