# ddns-go

> 自动把本机变化的公网 IP 同步到域名解析记录，解决动态 IP 无法固定访问的问题。

## 一句话总结

自动把本机变化的公网 IP 同步到域名解析记录，解决动态 IP 无法固定访问的问题。

## 核心功能 / 特点

- 定时读取本机公网 IP 并更新域名解析记录
- 支持阿里云、腾讯云、Cloudflare 等多家服务商
- 提供 Web 界面配置，支持 IPv4 与 IPv6

## 适用场景

- 家宽动态 IP 下用域名稳定访问自建服务
- 为软路由、NAS 等设备绑定固定域名
