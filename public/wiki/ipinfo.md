# IPinfo

> IP 地址查询服务，返回归属地、运营商与网络类型等信息。

## 一句话总结

IP 地址查询服务，返回归属地、运营商与网络类型等信息。

## 核心功能 / 特点

- 查询 IP 的国家城市、经纬度与运营商
- 提供 ASN、公司等网络归属数据
- 免费档每月五万次请求，返回 JSON

## 适用场景

- 登录风控中判断请求来源地区
- 按访客位置做内容或语言的分发
