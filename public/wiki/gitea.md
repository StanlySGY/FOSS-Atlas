# Gitea

> 轻量自建 Git 代码托管服务，占用低、部署简单。

## 一句话总结

轻量自建 Git 代码托管服务，占用低、部署简单。

## 核心功能 / 特点

- 提供仓库、Issue、Pull Request 等完整功能
- 支持组织、团队与细粒度的权限管理
- 内置 Actions 与包管理，便于协作扩展

## 适用场景

- 团队搭建私有代码仓库，代码不外流
- 在低配服务器或内网环境托管 Git 仓库
