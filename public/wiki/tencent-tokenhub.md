# 腾讯云 TokenHub

> 腾讯云 TokenHub 是大模型开发者 API 与模型服务入口，承接旧混元平台逐步迁移后的模型接入与资源管理。

## 一句话总结

腾讯云 TokenHub 是大模型开发者 API 与模型服务入口，承接旧混元平台逐步迁移后的模型接入与资源管理。

## 核心功能 / 特点

- 集中查看和调用腾讯云混元等大模型 API
- 旧混元体验资源包与新平台模型权益需按当前 TokenHub 账户和产品说明核对
- API 使用成本、模型路由及可用性按具体模型和云账号配置执行

## 适用场景

- 在自有应用中通过腾讯云开发者 API 接入混元模型
- 核对旧混元产品迁移后的模型入口与账户资源包

## 快速上手

- 进入 TokenHub 产品页并登录腾讯云账户，核对控制台当前可用模型与权益
- 创建或查看 API 密钥前先确认所选模型、区域和计费单位
- 首次开通旧混元平台资源包的账户应检查有效期及迁移后的具体规则

## 使用边界与安全提醒

- 旧混元资源包仅适用于官方列出的接口 / 模型与符合条件的账户，不能外推为 TokenHub 全部模型永久免费
- 消费者聊天产品与腾讯云开发者 API 是不同服务，额度与账单不互通
- 生产调用前应确认 TokenHub 实际模型定价、账户权限和 API 密钥安全
