# FastGPT

> 开源的知识库问答平台，围绕 RAG 提供数据导入与流程编排能力。

## 核心功能 / 特点

- 支持导入多种文档构建知识库
- 提供向量检索与对话流程编排
- 可对接多家大模型 API

## 适用场景

- 企业知识库的问答与智能客服
- 为内部文档搭一个检索问答入口
