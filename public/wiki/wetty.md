# Wetty

> 把终端搬进浏览器的开源工具，基于 xterm.js 通过网页连接 SSH 会话。

## 核心功能 / 特点

- 网页中打开终端，直接连接 SSH 或本地 shell
- 基于 xterm.js 与 WebSocket 实现实时交互
- 部署轻量，可反向代理后成 WebSSH 入口

## 适用场景

- 在浏览器里临时登录服务器执行命令
- 为不便安装 SSH 客户端的设备提供终端
