# Google AI (Gemini) API

> Google 的 Gemini 开发者接口，可在 AI Studio 试用并申请密钥。

## 核心功能 / 特点

- 提供 Gemini 系列多模态模型的调用接口
- AI Studio 中可直接试验提示词再取密钥
- 免费额度带速率限制，超出后按量计费

## 适用场景

- 快速验证提示词效果并接入应用
- 处理图文混合输入的生成类需求
