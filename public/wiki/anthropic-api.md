# Anthropic API

> Anthropic 官方接口，用于调用 Claude 系列模型完成对话与推理任务。

## 一句话总结

Anthropic 官方接口，用于调用 Claude 系列模型完成对话与推理任务。

## 核心功能 / 特点

- Claude 系列对话与推理模型的官方调用接口
- 原生支持工具调用、视觉理解与长上下文
- 按输入输出 token 用量计费

## 适用场景

- 需要长文档理解与严谨推理的产品功能
- 为应用接入稳定的多轮对话能力
