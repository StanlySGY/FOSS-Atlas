# Dify

> 开源的 LLM 应用开发平台，可视化编排应用、Agent 与知识库。

## 一句话总结

开源的 LLM 应用开发平台，可视化编排应用、Agent 与知识库。

## 核心功能 / 特点

- 可视化编排对话流程与工作流
- 内置知识库与 RAG 检索能力
- 提供 API 与嵌入方式对外发布

## 适用场景

- 快速搭建企业内部的 AI 应用
- 把知识库问答发布成可用的服务
