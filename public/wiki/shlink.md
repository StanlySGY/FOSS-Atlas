# Shlink

> 自建短链接服务，用来生成属于自己域名的短网址并统计点击。

## 核心功能 / 特点

- 生成自定义后缀的短链，可设置有效期
- 记录点击次数、来源与地理位置统计
- 提供 API 接口，支持绑定多个域名

## 适用场景

- 把长链接缩短后分享到社交平台
- 统计自己发布链接的点击情况
