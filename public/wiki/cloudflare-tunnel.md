# Cloudflare Tunnel

> 把本地服务通过 Cloudflare 网络发布到公网，无需公网 IP 也不用开放端口。

## 一句话总结

把本地服务通过 Cloudflare 网络发布到公网，无需公网 IP 也不用开放端口。

## 核心功能 / 特点

- 本地运行 cloudflared 建立出站隧道
- 绑定自有域名并自动配置 HTTPS
- 可结合 Zero Trust 做访问控制

## 适用场景

- 家用宽带下想对公网提供 Web 服务
- 临时把本地开发环境分享给他人调试
