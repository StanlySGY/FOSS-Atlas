# HFish

> 国产跨平台蜜罐平台，提供 Web 管理界面集中部署与查看各类蜜罐。

## 一句话总结

国产跨平台蜜罐平台，提供 Web 管理界面集中部署与查看各类蜜罐。

## 核心功能 / 特点

- 内置多种蜜罐模板，Web 界面即可部署
- 集中展示攻击来源、账号密码等捕获数据
- 支持多节点集群，可跨平台运行

## 适用场景

- 企业内网布设蜜罐发现横向渗透
- 用中文界面的平台做简单的安全监测
