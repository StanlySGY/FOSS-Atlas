# Supabase

> Supabase 是开源的 Firebase 替代方案，免费层提供托管 Postgres 与认证、存储等后端能力。

## 核心功能 / 特点

- 托管 Postgres 数据库，自带管理面板
- 内置认证、对象存储与实时订阅
- 自动生成 REST 与实时数据接口

## 适用场景

- 给前后端分离的项目配后端服务
- 快速搭一个带登录的 MVP 原型
