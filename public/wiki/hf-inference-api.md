# Hugging Face Inference API

> Hugging Face 的模型推理接口，用一套 API 调用平台上的开源模型。

## 核心功能 / 特点

- 统一接口调用社区里的各类开源模型
- 覆盖文本、图像、语音等多种任务
- 免费额度有限，可自建推理端点扩展

## 适用场景

- 快速试用某个开源模型而无需自己部署
- 为原型验证接入现成的推理能力
