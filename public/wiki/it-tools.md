# IT-Tools

> 面向开发者的在线小工具合集，把哈希、编码、正则测试等零散需求集中到一处。

## 核心功能 / 特点

- 涵盖编码转换、哈希、UUID、时间戳等工具
- 支持 Docker 自建，数据在本地处理
- 按类别检索，界面简洁易用

## 适用场景

- 临时做 Base64、JWT 解析等小操作
- 内网自建一套开发者常用工具页面
