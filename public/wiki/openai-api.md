# OpenAI API

> OpenAI 官方开发者平台，按用量计费调用 GPT 系列模型的能力。

## 一句话总结

OpenAI 官方开发者平台，按用量计费调用 GPT 系列模型的能力。

## 核心功能 / 特点

- 覆盖 GPT 系列文本与多模态模型的官方接口
- 支持函数调用、结构化输出与流式返回
- 按 token 用量计费，无需固定订阅

## 适用场景

- 把大模型能力接入自研应用或工作流
- 构建对话、摘要、代码生成等生产功能
