# GTFOBins

> 整理 Unix 上可被滥用的二进制程序清单，说明如何借此提权或读取文件。

## 一句话总结

整理 Unix 上可被滥用的二进制程序清单，说明如何借此提权或读取文件。

## 核心功能 / 特点

- 按提权、文件读写、反弹 shell 等能力筛选
- 给出针对每个二进制可直接照抄的命令
- 同时覆盖 sudo、SUID 与 capability 场景

## 适用场景

- 拿到低权限 shell 后寻找提权路径
- 审计系统上存在哪些危险的 SUID 程序
