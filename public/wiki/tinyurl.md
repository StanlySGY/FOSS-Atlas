# TinyURL

> 老牌免费短链接服务，可将长网址压缩为固定域名的短链。

## 核心功能 / 特点

- 把长网址转换为固定前缀的短链接
- 提供 API 供程序批量生成短链
- 注册后可自定义别名，链接长期有效

## 适用场景

- 分享长链接时避免过长参数
- 在二维码或短信中使用短链
