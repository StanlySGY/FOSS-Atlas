# qBittorrent

> 开源 BT 下载客户端，界面接近常见的桌面下载工具。

## 一句话总结

开源 BT 下载客户端，界面接近常见的桌面下载工具。

## 核心功能 / 特点

- 支持种子与磁力链接，可订阅 RSS 自动下载
- 内置搜索插件与 IP 过滤功能
- 提供 Web 界面，适合装在服务器远程管理

## 适用场景

- 在下载机上挂 BT 任务并远程查看进度
- 需要一个没有广告的桌面 BT 客户端
