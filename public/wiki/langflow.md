# LangFlow

> 可视化拖拽构建 LLM 工作流与 Agent 的低代码平台，节点连线即流程。

## 核心功能 / 特点

- 拖拽节点搭建检索、生成、分支等流程，无需写胶水代码
- 组件覆盖模型、向量库、工具调用与记忆
- 流程可导出为 API 端点，直接给外部应用调用

## 适用场景

- 快速验证一个 RAG 或 Agent 流程，再决定要不要写成代码
- 把已有的 LLM 调用链交给不太写代码的人维护和调整
