# ttyd

> 把命令行共享到浏览器的轻量工具，用一条命令即可开放 Web 终端。

## 核心功能 / 特点

- 启动即开放网页终端，通过 WebSocket 交互
- 可指定要运行的命令，做成固定入口
- C 语言编写，体积小，部署几乎无依赖

## 适用场景

- 临时分享终端给他人演示或协作
- 给自建服务提供简单的网页命令行
