# Forgejo

> 社区驱动的 Gitea 分支，强调开放治理与自托管。

## 一句话总结

社区驱动的 Gitea 分支，强调开放治理与自托管。

## 核心功能 / 特点

- 提供与 Gitea 类似的仓库、Issue 与 PR 功能
- 由社区治理，开发路线公开透明
- 支持 Actions 和包管理，可持续自托管

## 适用场景

- 看重社区治理而非公司主导的自托管团队
- 从 Gitea 迁移过来的私有代码托管需求
